# reports

Public reports and small apps for the team, served by GitHub Pages at
https://ghostbusters-repo.github.io/reports/ . One folder per report, grouped by project, each
with a self-contained `index.html`. The root `index.html` is the table of contents.

Everything here is on the open internet. No customer or patient data, no credentials, no numbers
that should stay inside the company. Publishing rules: `workspace/projects/reports.md`.
